# Negation Embedding in Ontology

This project aims to attack on the problem of the negation in ontologies.
We categorize the existing method into 3 types: Geometric, Sequence and Neural.
Geometric method represents axioms and entities as geometric shapes in the space(e.g., boxes, balls, or cones).
A close shape like boxes and balls are inherently hard to represent negation.

Cones don't have empirical experiments so far.

Squence methods do not deal with the negation so far.

Neural method like Logic Tensor Networks seems promising in this topic.
